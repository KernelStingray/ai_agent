# 🚀 OmniAgent Local — Автономная AI-станция

**OmniAgent Local** — это локальная веб-платформа с ИИ-ассистентом, спроектированная для работы без цензурных рамок, с полной защитой приватности, возможностью генерации офисных документов (`.xlsx`, `.docx`, `.pptx`, `.pdf`, `.zip`), проверкой кода во встроенной песочнице и стилистическим «стелс-режимом» для обхода AI-детекторов.

Система оптимизирована под работу на локальном компьютере с **50 ГБ оперативной памяти (RAM) и 8-ядерным процессором Intel Core i7 (без дискретной видеокарты)**.

---

## ✨ Ключевые возможности

1. **Генерация полноценных файлов и документов:**
   * 📊 **Excel (`.xlsx`):** создание форматированных таблиц со стилями, формулами (`SUM`, `AVERAGE`), авторасчетом ширины колонок и чередующейся заливкой (Zebra).
   * 📝 **Word (`.docx`):** структурированные аналитические отчеты с титульными листами, колонтитулами, таблицами и врезками.
   * 📽️ **PowerPoint (`.pptx`):** современные презентации 16:9 в темной или светлой теме со слайдами-карточками и списками тезисов.
   * 📄 **PDF (`.pdf`):** документы полиграфического качества с полной поддержкой кириллицы (шрифты DejaVu Sans).
   * 📦 **Архивы проектов (`.zip`):** сборка кодовых репозиториев с `Dockerfile`, `docker-compose.yml` и скриптами.
2. **Верификация и песочница (Execution Sandbox):**
   * Все расчеты и код генерации файлов автоматически исполняются в изолированном Python-процессе.
   * **Reflection Loop (самоисправление):** если сгенерированный код завершился с ошибкой, агент перехватывает `traceback`, автоматически исправляет скрипт и доводит его до 100% рабочего результата перед отправкой пользователю.
3. **Стелс-режим (Anti-Detection & Humanizer):**
   * Вырезание характерных для нейросетей штампов (*«в заключение»*, *«стоит подчеркнуть»*, *«является ключевым фактором»*).
   * Повышение показателя *Burstiness* — естественное чередование коротких и сложных предложений, активный залог.
4. **Премиальный двухоконный интерфейс (Split-View):**
   * Слева — интерактивный диалог с поддержкой Markdown, подсветкой синтаксиса и индикацией статуса в реальном времени.
   * Справа — Центр артефактов со списком готовых файлов, кнопками быстрого скачивания и консолью вывода песочницы.

## 🛠️ Системные требования

* **ОС:** Linux
* **Процессор:** 8 ядер (выделяется 6–7 потоков под генерацию)
* **Оперативная память:** 50 ГБ (рекомендуемый квант моделей `Q5_K_M` или `Q4_K_M`)
* **Python:** 3.10+

## ⚡ Быстрый старт

### Вариант 1: Запуск через Docker (Агент + Cloudflare Tunnel в 1 контейнере) 🐳

Контейнер автоматически собирает окружение с Python, ReportLab шрифтами и Cloudflare Tunnel, поднимает сервер и генерирует публичную ссылку:

```bash
# Запуск через удобный скрипт:
./docker-run.sh

# Либо напрямую через docker compose:
docker compose up --build -d
```

* После старта в консоли появится локальная ссылка `http://localhost:8000` и защищенная публичная ссылка Cloudflare (`https://*.trycloudflare.com`).
* **Логи и ссылка туннеля:** `./docker-run.sh logs` (или `docker compose logs -f omniagent`).
* **Остановка:** `./docker-run.sh down` (или `docker compose down`).
* Все сгенерированные файлы сохраняются локально в папке `backend/storage/artifacts`.

---

### Вариант 2: Локальный запуск без Docker

1. **Запустите сервер:**
   ```bash
   ./run.sh
   ```
2. **(Опционально) Запустите туннель в отдельном окне:**
   ```bash
   ./tunnel.sh
   ```
3. Откройте в браузере: **`http://localhost:8000`**

## 🧠 Подключение локальных моделей через Ollama

Для работы нейросетевого ядра используется локальный движок [Ollama](https://ollama.com/).

Рекомендуемые команды для скачивания моделей:
```bash
# 1. Золотой стандарт (умная и быстрая модель 14B):
ollama run qwen2.5:14b

# 2. Модель без цензуры (Abliterated):
ollama run hf.co/huihui-ai/Qwen2.5-14B-Instruct-abliterated-GGUF:Q5_K_M

# 3. Дистилляция Claude Fable 5:
ollama run parable/fable

# 4. Максимальный интеллект для сложной архитектуры (32B):
ollama run qwen2.5:32b
```

## 📁 Структура проекта

```text
ai_agent/
├── Dockerfile                     # Сборка образа (Python + cloudflared + шрифты)
├── docker-compose.yml             # Оркестрация с network_mode: host и томами хранения
├── entrypoint.sh                  # Точка входа: запуск FastAPI + Cloudflare Tunnel + shutdown trap
├── docker-run.sh                  # Управление контейнером (up, logs, down)
├── .dockerignore                  # Исключение временных и виртуальных директорий
├── run.sh                         # Скрипт локального запуска без Docker
├── tunnel.sh                      # Скрипт запуска туннеля без Docker
├── TZ.md                          # Полное утвержденное Техническое Задание
├── README.md                      # Документация и руководство пользователя
├── requirements.txt               # Список зависимостей Python
│
├── backend/                       # Бэкенд на FastAPI
│   ├── main.py                    # Роутинг, SSE стриминг, эндпоинты артефактов и статуса
│   ├── config.py                  # Конфигурация портов, потоков и путей
│   ├── agent/                     # Агентный оркестратор и промпты
│   │   ├── prompts.py             # Стелс-промпты, инструкции генерации и рефлексии
│   │   ├── tools.py               # Утилиты работы с артефактами
│   │   └── orchestrator.py        # Управление диалогом и циклом автоисправления
│   ├── sandbox/                   # Локальная песочница
│   │   └── executor.py            # Изолированное выполнение Python кода
│   ├── generators/                # Модули стилизации и создания файлов
│   │   ├── excel_gen.py           # .xlsx (openpyxl)
│   │   ├── word_gen.py            # .docx (python-docx)
│   │   ├── pptx_gen.py            # .pptx (python-pptx)
│   │   ├── pdf_gen.py             # .pdf (reportlab с поддержкой кириллицы)
│   │   └── zip_gen.py             # .zip (архиватор проектов)
│   └── storage/
│       ├── artifacts/             # Папка со всеми сгенерированными файлами
│       └── cloudflared.log        # Логи туннеля Cloudflare
│
└── frontend/                      # Клиентский интерфейс (Split-View)
    ├── index.html                 # Главная страница с бейджем туннеля и чатом
    ├── css/style.css              # Стили (Modern Dark Glassmorphism)
    └── js/
        ├── app.js                 # Инициализация, SSE-стриминг, поллинг статуса и URL туннеля
        ├── chat.js                # Рендеринг Markdown и сообщений
        └── artifacts.js           # Панель управления и скачивания файлов
```
